¿Cómo utilicé la IA?

Utilicé la IA como una herramienta de apoyo mientras hacía este sitio web. Su función fue ayudar a planificar, redactar, revisar y mejorar diferentes partes del proyecto, especialmente la estructura HTML, los estilos CSS y la programación JavaScript.

La IA también ayudó a detectar problemas en el código. Por ejemplo, la utilicé para organizar los mini quizzes de los cinco cursos y mejorar su accesibilidad.

Cuando la IA terminó el código, lo revisé yo para ver si concordaba con lo que quería y si cumplía la mayoría de los requisitos del proyecto.

¿Qué partes del sitio web hizo la IA?

La IA contribuyó en diferentes etapas del desarrollo del sitio web.

  • Organización de la estructura de las páginas HTML.
  • Redacción y adaptación de contenidos educativos para los diferentes cursos.
  • Creación y revisión de los estilos CSS.
  • Programación de los mini quizzes mediante JavaScript.
  • Implementación de características de accesibilidad.
  • Detección y corrección de errores en el código.
  • Organización de los archivos del proyecto.

A continuación mostraré cinco de los prompts que más contribuyeron al desarrollo del proyecto y una explicación de lo que aportó cada uno.

2. Creación del diseño CSS

Prompt utilizado:

Creación de los archivos CSS

Para diseñar y organizar la apariencia de Cristiancursos se crearon dos archivos CSS separados: estilos.css y responsivo.css. Esta separación permite mantener el código organizado y facilita realizar cambios en el diseño sin modificar el contenido HTML.

Archivo estilos.css

El archivo estilos.css contiene los estilos principales del proyecto. En él se definieron variables mediante :root para mantener una selección coherente de colores, tipografías, espaciados, bordes, sombras y otros elementos visuales.

También se utilizaron diferentes tipos de selectores CSS, incluyendo selectores de tipo, clase, identificador, descendientes, hijo directo, agrupados y de atributo. Esto permitió aplicar los estilos de manera organizada aprovechando la estructura HTML existente.

Para la distribución de los elementos se utilizó Flexbox en el encabezado y la navegación, mientras que el catálogo de cursos utiliza CSS Grid para organizar las tarjetas de los cursos.

Las tarjetas y los botones incluyen efectos de interacción mediante :hover, :focus y :active, además de transiciones para que los cambios visuales sean más suaves. También se utilizó :nth-child() para aplicar pequeñas variaciones de diseño a las diferentes tarjetas del catálogo.

Se prestó especial atención a la accesibilidad. Se utilizaron colores con buen contraste y se incorporó un indicador de foco visible para facilitar la navegación mediante teclado.

Archivo responsivo.css

El archivo responsivo.css se encarga de adaptar el sitio a diferentes tamaños de pantalla. Se utilizaron reglas @media para modificar el diseño en dispositivos de tamaño mediano y pequeño.

En pantallas más pequeñas se ajustan el encabezado, la navegación, el catálogo de cursos, las tarjetas, los botones, los tamaños de texto y los espacios entre elementos.

También se controlaron los tamaños de los elementos para evitar que aparezca desplazamiento horizontal innecesario en teléfonos y otros dispositivos móviles.

Objetivo del diseño

El objetivo de estos archivos CSS fue crear un diseño moderno, limpio, profesional y fácil de utilizar, manteniendo una apariencia coherente en todas las páginas de Cristiancursos y aprovechando la estructura HTML existente.

Requisitos técnicos utilizados

  • Se utilizaron variables CSS mediante :root.
  • Se definieron fuentes diferentes para títulos y textos.
  • Se utilizaron selectores de tipo, clase, ID, descendientes, hijo directo, agrupados y de atributo.
  • Se aplicaron margin, padding, border y box-sizing: border-box.
  • Se utilizó Flexbox en el encabezado y la navegación.
  • Se utilizó CSS Grid en el catálogo de cursos.
  • Se incorporaron :hover, :focus, :active y :nth-child().
  • Se añadieron transiciones a los botones y tarjetas.
  • Se mantuvo un buen contraste de colores.
  • Se añadió un foco visible para mejorar la navegación con teclado.
  • Se utilizaron diferentes reglas @media para adaptar el sitio a distintas pantallas.
  • Se controló el diseño móvil para evitar scroll horizontal.

¿Qué aportó?

Este prompt ayudó a crear una identidad visual coherente para el sitio. También permitió organizar variables de colores, tamaños, espaciados, bordes, sombras y estados de interacción. Además, contribuyó a que el sitio pudiera adaptarse a diferentes tamaños de pantalla.

3. Creación de los mini quizzes

Prompt utilizado:

Crea mini quizzes para cada uno de los cinco cursos usando JavaScript. Cada pregunta debe tener varias opciones y una sola respuesta correcta. Al finalizar, mostrar la puntuación y un mensaje según el resultado. Permitir reiniciar el quiz sin recargar la página y validar que todas las preguntas tengan una respuesta.

¿Qué aportó?

Este prompt permitió desarrollar los mini quizzes con JavaScript.

4. Mejora de accesibilidad

Prompt utilizado:

Mejora la accesibilidad de los mini quizzes. Utiliza fieldset y legend para las preguntas, controles de formulario reales, aria-live para anunciar el resultado, navegación completa mediante teclado, foco visible y una forma de indicar las respuestas correctas e incorrectas que no dependa únicamente del color.

¿Qué aportó?

Este prompt permitió mejorar la accesibilidad del sitio web, permitiendo utilizarlo mediante el teclado y facilitando la navegación con lectores de pantalla.

5. Detección y corrección de errores

Prompt utilizado:

Revisa este código HTML y JavaScript y encuentra por qué el mini quiz no aparece correctamente en la página. Corrige los errores sin eliminar el contenido existente y asegúrate de que la ruta del archivo JavaScript sea correcta.

¿Qué aportó?

Este prompt fue importante para identificar errores de integración entre HTML y JavaScript. Permitió revisar las rutas de los archivos, los elementos que utiliza JavaScript y la forma en la que inician los quizzes.

También se usaron muchos otros prompts, pero solo eran para corregir errores pequeños en el JavaScript. Los que están presentes aquí son los que más contribuyeron al sitio web.

Principales contribuciones de la IA

La utilización de IA permitió avanzar en diferentes aspectos del proyecto de manera más organizada.

  • HTML: ayudó a estructurar las páginas y organizar las diferentes secciones de los cursos.
  • CSS: ayudó a crear un diseño visual consistente.
  • JavaScript: permitió desarrollar los mini quizzes.
  • Accesibilidad: ayudó a incorporar elementos como navegación mediante teclado.
  • Corrección: ayudó a localizar errores de sintaxis, rutas y conexión entre los archivos.
  • Organización: permitió mantener separados los archivos HTML, CSS y JavaScript para facilitar el mantenimiento del proyecto.

Conclusión

Usé la IA para crear la mayoría del sitio web, pero yo revisaba el código y probé el sitio web de bastantes maneras para ver si era funcional.
